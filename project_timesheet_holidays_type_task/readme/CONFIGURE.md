1. Go to *Time Off → Configuration → Time Off Types* and open a time off type.
2. In the *Configuration* section, set the *Timesheet Project* and optionally the *Timesheet Task*.
3. The company-wide internal project and time off task (Settings → Time Off) must still be configured (they are created automatically) — they remain the fallback for types without their own project.

Note: the fields are hidden for types counted as *Worked Time*, since no timesheets are generated for those.
